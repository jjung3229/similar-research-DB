# 토지세목조서 PDF → 엑셀 변환기

도로구역 결정 고시문 등에 붙는 **「수용할 또는 사용할 토지세목조서」** 표를
PDF에서 그대로 읽어 엑셀(.xlsx)로 바꿔 줍니다. 손으로 옮겨 적던 작업을 없애기 위한 도구입니다.

실제 고시문(고속국도 제140호 계양~강화선, 87쪽)으로 확인한 결과
**2,984건을 30초 만에** 옮겼고, 각 구간의 번호가 1번부터 빠짐없이 이어지는지와
고시문에 인쇄된 소계와 합산값이 맞는지까지 자동으로 검사합니다.

## 설치 (처음 한 번만)

```bash
pip install -r requirements.txt
```

## 쓰는 방법 1 — 끌어다 놓기 (권장)

```bash
python app.py
```

브라우저가 열리면 PDF를 상자에 끌어다 놓고 **엑셀 내려받기**를 누르면 됩니다.
여러 개를 한꺼번에 올려도 됩니다. 파일은 이 컴퓨터 안에서만 처리되며 외부로 전송되지 않습니다.

## 쓰는 방법 2 — 명령줄

```bash
python land_schedule.py 고시문.pdf                # 고시문.xlsx 생성
python land_schedule.py 고시문.pdf -o 결과.xlsx
python land_schedule.py *.pdf -d 결과폴더/        # 여러 개 한꺼번에
```

실행하면 이렇게 요약이 나옵니다.

```
[완료] 고시문.pdf → 고시문.xlsx
       자료 2,984건 / 소계 26행 / 표 86쪽 (전체 87쪽)
       소계 검증: 26개 구간 중 3개가 고시문 소계와 다름 — 「검증」 시트 확인
```

## 만들어지는 엑셀

| 시트 | 내용 |
| --- | --- |
| **토지세목조서** | 본표. 연번 + 원본 번호 + 소재지·지번·지목·지적·편입면적·소유자·이해관계인·비고 + 원본 쪽수. 첫 줄 고정, 필터 걸려 있음 |
| **소계** | 고시문에 인쇄된 소계 행만 모음 |
| **검증** | 구간별로 `직접 합산값 ↔ 고시문 소계`를 비교. 차이가 나는 줄은 빨갛게 표시 |
| **지목별 요약** | 지목(답·전·도·구·임…)별 건수와 면적 합계 |

면적은 문자열이 아니라 **숫자**로 들어가므로 바로 합계·정렬·피벗을 쓸 수 있습니다.

## 어떻게 읽는가

- 표의 머리글(번호/소재지/지번/지목/지적/편입면적/소유자/이해관계인/비고)을 **읽어서**
  열 구성을 잡습니다. 고시문마다 열이 조금 달라도 그대로 따라갑니다.
- 한 필지가 여러 줄에 걸쳐 인쇄된 것(소재지가 2줄, 주소가 3줄 등)을 한 행으로 합칩니다.
- 페이지마다 반복되는 머리글, 첫 장의 고시 본문은 걸러 냅니다.
- 번호가 셀 가운데 정렬 때문에 자료보다 한 줄 아래에 찍히는 경우까지 처리합니다.
  (실제 고시문에 이런 필지가 있어 그냥 읽으면 두 필지가 한 줄로 붙습니다.)

## 검증 결과 보는 법

「검증」 시트의 `차이` 열이 0이면 그 구간은 한 건도 빠지지 않은 것입니다.
0이 아니라면 두 가지 경우입니다.

1. **고시문 자체의 소계가 맞지 않는 경우** — 위 예시의 3개 구간이 여기 해당합니다.
   예를 들어 김포시 감정동 12필지의 지적 합은 32,164.0㎡인데 고시문 소계는 43,083.0㎡로
   인쇄돼 있습니다. 원본을 확인해 보면 표에 적힌 값 그대로를 옮긴 것이 맞습니다.
2. **읽기가 잘못된 경우** — 이때는 해당 쪽수를 열어 눈으로 대조해 주세요.

구분이 필요하면 「토지세목조서」 시트의 `페이지` 열로 원본 쪽을 바로 찾아갈 수 있습니다.

## 한계

- **글자가 들어 있는 PDF**만 됩니다. 스캔한 이미지 PDF는 먼저 OCR이 필요합니다.
- 표에 선이 그어져 있어야 합니다(고시문 양식은 모두 해당).
- 이름·주소가 `송**`처럼 가려진 것은 원문 그대로 옮깁니다.
